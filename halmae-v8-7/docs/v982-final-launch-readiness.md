# v9.8.2 출시 차단 점검

## 공급·환불·증빙

- 구매 상품은 39,900원 단건, 26장 전체와 2027년 월별 풀이, 승인 시각부터 365일이다. 장부 생성과 보고서 응답은 26장을 일괄 처리한다. 결제 승인, 열람 제공 가능 시점, 최초 성공 응답 준비 시점, 실제 고객의 열람은 별개다. 최초 응답 준비 기록만으로 실제 읽거나 계약서면을 받았다고 판단하지 않는다.
- 단일 가격과 일괄 제공은 가분성 판단 요소다. 법적 불가분성과 실제 제공 개시는 사실관계와 법률 검토로 판단한다. 사전 고지, 공급 개시 및 시험 사용 제공 등 요건이 충족된 범위에서 제한을 적용한다. 미제공 가분 부분, 오발급·미제공·하자·법정 예외는 보장한다. 중복 결제는 중복분을 환불하고 고객 입력 오류는 제공 전 정정, 제공 후엔 실제 공급 및 귀책을 확인해 처리한다.
- 페이앱 부분 환불 통지는 기존 승인 증빙과 만료가 유효한 전체 장부 열람을 자동 박탈하지 않도록 했다. 정상 확인된 전액 취소와 365일 만료에는 열람을 차단한다. 부분 환급을 여러 번 진행하여 전액 상당이 되는 건, 페이앱 관리자의 일부 취소 후 잔액 정산, 토스의 기존 부분취소 동작은 승인 및 대조가 필요하다. 일부 장만 제외하는 권한 설계는 현 상품에 없다.
- 최초 장부 응답 준비 시각을 주문번호·만료 일시만 포함해 주문 저장소와 분리된 법정 기록에 기록한다. 별도 보존본은 최초 기록 기준 5년 범위의 기존 파기 처리와 보존 유예 절차를 적용한다. 본문, 출생 정보, 이메일과 열람 링크는 분리본에 담지 않는다. 주문별 정책 원문·버전·동의, 계약서면, 결제와 환불 기록은 유형별 보존 점검을 한다. 페이앱 환불 이력과 메일 접수·실패의 전체 이력을 별도 법정 보존본으로 대조하는 절차는 별도 검증이 필요하다. 광고 6개월, 계약·청약철회와 결제·공급 5년, 불만·분쟁 3년 보존을 적용한다.

공식 근거 [전자상거래법 제17조](https://www.law.go.kr/법령/전자상거래법/제17조) · [시행령 제6조 및 제21조의2](https://www.law.go.kr/법령/전자상거래등에서의소비자보호에관한법률시행령)

## 결제 잠금 상태에서 이메일 검수

1. 기존 도메인 인증·키·HTTPS 상태는 재설정하지 않는다. 먼저 출시 후보와 동일한 코드의 격리 환경에서 가상 주문 및 메일 모의 테스트를 실행한다. 승인 전 지급 권한이 없고, 정상 승인 뒤 구매 당시 정책 원문이 교부 기록과 일치하는지 본다. 같은 공급사 통지의 재전송, 일시 실패, 반송 처리를 점검한다.
2. 운영자 승인 후 운영 사이트와 별도로 접근 제한된 Netlify 테스트 사이트를 사용한다. 판매 플래그는 잠근다. 담당자만 실행할 수 있는 제한된 로컬 또는 CI 절차에서 합성 주문을 만들고 허용된 자체 네이버·Gmail 주소로만 메일을 검수한다. 인증 우회, 공급사 통지 위조, 공개 발송 API는 사용하지 않는다. 운영 사이트에서 판매를 잠근 상태로 전체 자동 경로를 실행할 승인된 테스트 방법과 권한이 없으면 운영 경로는 미검증으로 기록한다.
3. 테스트 메일의 Resend 발송 이벤트와 받은편지함·스팸함을 별도로 대조한다. 계약서면 발송·반송·재교부 시각과 최초 제공 시점을 확인하며 실패 시 본인 확인 후 구매 당시 보관본을 재교부한다. 복구에서는 새 브라우저와 다른 기기, 링크 만료·일회 사용·재발급을 검수하고 실제 주소나 토큰을 증빙에 남기지 않는다.
