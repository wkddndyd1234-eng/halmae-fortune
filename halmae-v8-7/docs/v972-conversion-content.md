# v9.7.2 콘텐츠와 구매 동선 검수

- 기준 `ee7929e8caa5a6b9a23ff2d03ace223f80ab8d72`. 상품 조건은 39,900원 단건, 26장, 2027년 12개월, 승인 시각부터 365일 열람이다.
- 무료 입력에서 이름을 첫 필드로 옮기고 연애 상태는 선택 영역에 둔다. 입력 이름 그대로 호명하고, 사주 계산에 사용하지 않는다. 기존 주문 API와 보관 주문의 이름 없는 데이터도 호환된다.
- 무료 핵심 본문은 장면·행동을 먼저 말한다. 유료 본문은 도입, 삶의 주제, 2027년과 월별 장을 손봤고, 근거를 필요한 위치에서 펼쳐 읽을 수 있다. 명식 계산, 월별 관계와 절기 계산은 변경하지 않았다. 기존 발급 완료본은 저장 방식과 재열람 경로를 유지한다.
- 제14장 발췌는 무료 결과와 주문 화면, 유료 보고서가 같은 문장 생성기를 사용한다. 상품과 가격을 앞에 표시하고 결제 전 고지와 정책 링크를 유지한다. 모바일의 균형 줄바꿈과 버튼 폭을 보강했다.
