# v9.8.1 출시 정책 검수본

운영 도메인 지정값: https://halmae.jector.kr. 실제 판매 및 DNS, Resend 설정은 변경하지 않았다.

- 고객센터 번호 원천은 `LIVE_SUPPORT_PHONE` 하나다. Netlify의 같은 사이트 설정값을 빌드와 Functions 범위에 공통 적용한다. 번호 변경 후 승인된 빌드와 서버 설정을 함께 반영한다. 새 계약서면부터 교체하며 이미 보존된 계약서면의 전화번호는 그대로 유지한다. 임시 개인번호는 비공개 검수 빌드에만 넣고 GitHub에는 저장하지 않았다.
- 계약 원문은 `LIVE_POLICY_VERSION`과 `LIVE_POLICY_ARCHIVE_JSON`, 세 정책 URL로 보관한다. 운영 승인 후 세 페이지의 확정 원문과 동일한 새 버전을 등록한다. 기존 원문을 덮어쓰지 않는다. 주문에 고지 확인, 즉시 제공 요청, 약관 동의, 원문 해시와 서버 동의 시각을 기록한다.
- 제공 근거는 최초 성공 장부 응답 준비 시각이다. 이 시각은 사용자가 실제로 읽은 사실이나 이메일 수신을 뜻하지 않는다. 추가 페이지별 추적은 하지 않는다. 최초 제공 기록은 현재 고객 주문 저장소에 있으며 소거된 뒤에도 필요한 법정 공급 증빙의 분리 보존 기간과 방법은 운영 승인 전에 확정한다.
- 전자상거래법 제13조, 제17조, 제18조 및 시행령 제6조·제21조의2를 참고했다. 점신 공개 약관은 구성 참고용이다. 제14장 발췌는 일부 이용 허용의 후보이며 현재 문구와 실제 보기 접근성을 별도로 검토해야 한다. 동의만으로 철회 권리가 사라지지 않는다.
- 출시 차단 항목은 신고번호·기관, 업무용 전화 교체, 시행일, 약관·환불 승인, 가분성 및 부분 환급 후 열람권, 실제 계약서면 교부 확인, 페이앱 가맹점·정산 및 실제 복귀 검증이다.
- 개인정보 운영 전 확인: Netlify와 Resend가 처리하는 국가·수탁 범위·보유기간과 국외 이전 근거, 실제 로그/캠페인/발송 대기 및 반송 보존 기간, 연락처와 거부 절차 공개. 사업자가 실제로 운영 설정을 확인할 때까지 해당 내용을 법적 확정본으로 게시하지 않는다.
- 공정위 조회 링크는 일반 통신판매사업자 검색이다. 해당 사업자의 신고번호나 조회 성공을 가정하지 않는다. 외부 사이트 403으로 목적 페이지는 별도 실브라우저 확인이 필요하다.
