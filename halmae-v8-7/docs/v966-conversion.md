# v9.6.6 구매 동선 검증

- 첫 화면에서 할매 캐릭터와 2027년 신년운세를 함께 보여준다. 400 × 877 모바일 에뮬레이션에서 스크롤 없이 무료 풀이를 열 수 있다.
- 무료 풀이에 필요한 출생 정보를 먼저 받고, 닉네임과 관계 정보는 선택 항목에 둔다. 무료 결과 다음에 계산한 명식으로 만든 유료 장부의 2027년 장 일부를 보여준다.
- 상품 소개는 26장과 2027년 12개월 구성부터 설명한다. 결제 화면에는 39,900원 단건 결제, 결제 승인 후 열람, 승인 시각부터 365일, 청약철회 안내를 표시한다.
- 주문 화면에서 출생 정보를 요약하고 수정은 펼쳐서 한다. 출생 정보 확인, 약관, 개인정보, 즉시 제공 동의는 각각 유지한다.

## 전환 이벤트

| 이벤트 | 기록 시점 |
| --- | --- |
| home_view | 홈 스크립트 초기화 |
| reading_start | 무료 풀이 시작 |
| reading_complete | 풀이 성공 |
| purchase_click | 무료 결과에서 구매 CTA 클릭 |
| checkout_view | 주문 화면 진입 |
| payment_approved | 결제 승인 API 성공 응답 |
| test_payment_approved | 로컬 모의 승인 |

허용된 이벤트 이름과 불리언 값만 세션 스토리지에 저장한다. 같은 탭의 세션에서 단계별 한 번만 기록한다. 캠페인 귀속, 서버 집계, 브라우저 간 중복 제어는 미구현이다. 외부 광고 플랫폼 연동 전에 계측 목적과 수집 항목, 승인 주문 단위 중복 제어를 확인한다.

## 검증 범위

기존 77개 및 전환 중복·저장 데이터 검사 1개와 빌드가 통과했다. Edge PC와 모바일 에뮬레이션에서 가상 음력 윤달 출생 정보로 무료 풀이, 미리보기, 주문, 모의 승인과 계약서면 링크를 확인했다. 실기기, 운영 속도, 실결제, 실제 전환율 및 참고 사이트 비교는 미검증이다.

정식 출시 전에 사업자 증빙, 최종 환불 정책과 PG 승인, 운영 환경에서의 계약서면 교부 설정을 확인한다.
