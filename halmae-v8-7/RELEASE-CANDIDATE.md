## 상품과 테스트 결제

무료 체험은 브라우저에서 네 기둥과 일간·오행 등 핵심 결과를 표시한다. 상품 안내는 39,900원 예정가, 26장 구성, 가상 예시, 웹 열람 조건을 보여준다. 프리뷰의 카드 승인 후 발급한 웹 링크는 승인 시각부터 7일 동안 쓸 수 있다. 계정·이메일 루트는 없다. 관리자 발급 토큰과 테스트 결제 토큰은 별도 범위를 사용한다.

서버는 주문을 발급한 브라우저의 서명 토큰, 주문 번호, 원화 39,900원, 토스 결제 키, 카드 상태 및 잔액을 확인한다. 토스 승인 요청에는 주문과 결제 키에서 생성한 멱등 키를 쓰고, 재시도 전에 이미 승인된 주문을 조회한다. 보고서를 열 때도 토스에 현재 결제 상태를 조회한다. 링크 유효기간과 데이터 보관 기간은 별개다. 발급 시스템은 공용 저장소로 간섭하지 않도록 이 프로젝트의 Netlify Blobs를 사용한다. 사이트 안의 테스트 결제 이벤트는 브라우저 탭에서 횟수만 기록한다.

빌드 출력에는 허용 목록의 정적 파일만 포함한다. 보고서 원고와 서버 함수는 배포 웹 루트에서 다운로드할 수 없다. 공개 GitHub 저장소에 올라간 공통 템플릿 자체는 공개 범위에 속하며, 개별 주문과 생성 보고서는 서버에서 권한을 검사한다.

## 프리뷰 설정과 실제 출시 조건

- 기존 `halmae-fortune-v87-preview`에서 `test-v87`과 `halmae-v8-7` 프로젝트 경로의 연결을 확인한다. 실제 운영 Netlify 사이트는 별도로 유지한다.
- 프리뷰 함수 환경변수는 `PAYMENT_MODE=test`, `TOSS_TEST_CLIENT_KEY`, `TOSS_TEST_SECRET_KEY`, `REPORT_TOKEN_SECRET`, `DEMO_ACCESS_CODE`다. 토큰 서명 키는 32자 이상, 관리자 코드는 12자 이상이어야 한다. 실제 결제 키는 프리뷰 설정에 추가하지 않는다.
- PG 계약과 심사 후에는 별도 운영 설정 및 코드 심사를 거친다. 예정 환경변수 이름은 `TOSS_LIVE_CLIENT_KEY`, `TOSS_LIVE_SECRET_KEY`, 운영 전용 `REPORT_TOKEN_SECRET`이다. 명시적인 라이브 활성화 설정과 승인된 운영 호스트 분리는 이후 작업이며, 이 후보는 라이브 키나 라이브 모드를 허용하지 않는다.
- 출시 전 토스 테스트 키로 실제 프리뷰 승인·취소·중복 재시도와 복구를 확인한다. 실제 결제 환불 처리, 리다이렉트 이탈 시 주문 복구·정산 대조, 보관·자동 파기·삭제 절차, 최종 약관·청약철회 고지, 독립 만세력 경계 검증은 남아 있다.
- 39,900원 판매 전에는 공통 글과 원국 분석의 비중이 가격 기대에 맞는지 샘플 사용자로 검증한다. 현재 전환 이벤트는 탭 내부 점검용이라 방문자 전체의 전환율은 측정할 수 없다.

## 로컬 확인

프로젝트 폴더에서 `node --test`와 `node build.mjs`를 실행한다. Netlify CLI가 있는 경우 `netlify build --offline`으로 정적 파일과 함수 번들링을 확인한다. 로컬 테스트는 Netlify Blobs와 토스 결제 API를 대체해 실행하며, 프리뷰 실연동 결과는 배포 상태와 별도로 확인한다.
