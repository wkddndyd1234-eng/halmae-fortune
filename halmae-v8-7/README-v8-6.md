# 할매의 운명방 v8.6 — 전체 인생 장부 디자인 시제품

## 핵심 변경
- 기존 v8.5 홈페이지(index.html) 및 Netlify 주문/발급 인증 흐름 보존
- 주문 화면의 관심 분야 선택 삭제; 모든 고객에게 동일한 주제 범위 제공
- 보고서 24개 섹션(프롤로그, 9개 본편, 2027 부록 서문, 12개월, 에필로그) 구성
- 금빛 표지·목차·챕터별 페이지·웹 열람·브라우저 인쇄 PDF 디자인 추가
- 입력 생년월일/시각/요일과 달력상 계절 비유 반영, 실제 명리학 원국 계산으로 오인하지 않도록 표시

## 중요: 판매 금지 / 정확성
이 버전은 **보고서 UI/콘텐츠 확장 검증용 시제품**입니다. 실제 사주 네 기둥·오행·십성·대운·2027년 세운/월운 계산은 구현되지 않았습니다. 2027년 월별 내용은 **공통 성찰 가이드**이지 개인 운세 예측이 아닙니다. 판매 전에 검증된 만세력 엔진, 개인별 해석 로직, 출생력 입력(음력/윤달), 상품 고지와 정책 검토, PG 승인/결제 검증이 필요합니다.

## 배포 (기존 GitHub 저장소 유지)
1. GitHub `halmae-fortune` 저장소의 `halmae-v8-5` 폴더 안 파일들을 **이 ZIP의 `halmae-v8-5` 폴더 내용으로 교체**합니다. 폴더명은 그대로 유지해 Netlify 기본 디렉터리 설정을 변경할 필요가 없습니다.
2. 변경 사항 커밋 후 Netlify `Published` 확인.
3. Netlify 환경변수 `DEMO_ACCESS_CODE`, `REPORT_TOKEN_SECRET`은 기존 설정 유지. 코드나 GitHub에 값 기입 금지.
4. 테스트 주문 → 관리자 테스트 발급 → 웹 보고서 열람 → PDF 인쇄 저장 확인.
5. 기존 발급된 테스트 보고서 링크는 토큰 만료 전에는 새 보고서 UI로 표시될 수 있습니다.

## 주의
- 프리미엄 보고서의 표지와 장 구성은 확장했지만, 동일 출생 계절의 본문 상당 부분이 공통입니다. 개인별 완성도/정밀 명리 검증 전 19,900원 판매용으로 사용하지 마세요.
- 테스트 주문은 개인정보를 저장합니다. 실제 고객 정보를 입력하지 말고 가상 테스트 정보만 사용하세요.
- `index.html`의 기존 무료 체험 관심분야 선택은 유지되어 있습니다. **이번 수정은 유료 주문에서 선택을 없앤 것**입니다. 다음 UI 정리에서 메인 무료 체험도 통일해야 합니다.
- 인쇄 결과는 브라우저마다 페이지 나눔이 다를 수 있으므로 Chrome PDF 미리보기 검수가 필요합니다.
