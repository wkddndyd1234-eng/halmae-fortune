개인정보처리방침 (오픈 전 안내)

서비스 오픈 전 검토용 안내입니다. 실제 유료 결제는 운영하지 않습니다. 프리뷰에서는 가상 입력과 테스트 카드로 주문·발급을 점검할 수 있습니다. 실제 운영·결제 방식이 확정되면 내용을 재검토하고 시행일을 표시합니다.

1. 현재 체험판의 처리 방식

현재 제공하는 정적 HTML 체험판에서는 사용자가 입력한 양력 생년월일과 출생 시간으로 브라우저 안에서 무료 풀이를 계산합니다. 무료 풀이 입력은 서버로 보내지 않습니다. 이 탭에서 무료 결과를 읽고 주문 화면으로 이동할 때 별칭·양력 생년월일·출생 시각만 탭 저장소에 잠시 보관해 입력을 이어갑니다. 관계 상태는 저장하거나 주문으로 보내지 않습니다. 입력을 지우거나 주문을 만들거나 탭을 닫으면 이어가기 정보가 삭제됩니다.

2. 외부 서비스 관련 안내

웹 호스팅 사업자(Netlify)는 사이트 접속 과정에서 IP 주소, 접속 기록 등 기술적 정보를 자체 정책에 따라 처리할 수 있습니다. 관련 내용은 호스팅 사업자의 개인정보 안내를 확인해 주세요.

3. 프리뷰 테스트 주문

가상 양력 생년월일, 선택한 출생 시간·별칭, 주문 번호·상태, 테스트 승인 식별자와 승인 시각을 보고서 발급 및 검증을 위해 Netlify에 저장합니다. 성별과 전화번호는 받지 않습니다. 복구에 별도 동의하면 이메일 주소를 대조용 검증값으로 변환해 보관합니다. 복구 요청에서 입력한 주소가 일치할 때 그 주소로만 Resend가 메일을 보냅니다. 메일에 생년월일과 카드 정보를 넣지 않습니다. 결제창은 토스페이먼츠가 제공하며 카드 정보는 할매의 운명방 서버가 직접 받지 않습니다.

승인 거래의 주문 번호, 승인 식별자와 시각, 열람 만료 시각, 보고서 생성에 필요한 양력 생년월일과 선택 시각·별칭 및 선택 복구 검증값은 열람 종료까지 보관합니다. 열람 권한은 승인 시각부터 365일입니다. 예정된 삭제 작업에서 만료 기록을 삭제하며, 미승인 및 관리자 테스트 기록은 30일 기준으로 정리합니다. 자동 삭제는 지정한 프리뷰에서 설정하고 검증한 후 가동합니다.

같은 브라우저에서 새 링크를 받기 위한 보안 쿠키, 최근 주문 번호와 짧은 열람 링크를 사이트 데이터에 저장합니다. 복구 메일 링크는 최대 15분·1회이며, 웹 열람 링크는 최대 30분입니다. 무료 풀이·구매 단계별 이벤트 이름, 화면 유형과 횟수만 탭 안에 보관하며 서버에 전송하지 않습니다. 출생정보·이메일·주문 번호는 이 집계에 포함하지 않습니다. 주문 화면에서 사이트에 저장된 테스트 열람 정보를 지울 수 있습니다. 서버 기록이나 발송 메일의 삭제는 문의처로 요청해 주세요.

서버 기록 삭제나 이메일 복구 동의 철회를 요청하면 본인 확인 후 처리합니다. 보고서 생성 정보를 삭제하면 남은 기간에 보고서를 제공할 수 없으며, 복구 검증값만 삭제하면 이메일 복구만 중단됩니다. 실제 판매 시 법령이 보존을 요구하는 거래·분쟁 기록은 필요한 항목만 보고서 데이터와 분리해 법정 기간 동안 보관하고, 기간이 끝나면 파기합니다. 프리뷰 테스트에는 실제 청구가 발생하지 않습니다.

4. 유료 서비스 전환 시

향후 결제·자동 발급 기능을 도입하면 주문자 연락처, 결제 식별 정보, 보고서 발급에 필요한 출생 정보 등을 처리할 수 있습니다. 이 경우 수집 항목·목적·보유기간·위탁사·국외 이전 여부·파기 절차 등을 실제 구현에 맞춰 명시하고 필요한 동의 및 고지를 진행합니다.
