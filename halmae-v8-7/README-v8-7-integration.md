## 검증과 한계
- 테스트는 일주 기준일과 입력 검증을 다룹니다.
- 기존 무료 체험판에 내장된 절기 데이터에 의존합니다. 절기 경계, 23시 자시, 출생지 태양시, 시간대, 전 범위의 회귀 테스트는 추가 검증이 필요합니다.
- 출생 시각 미상 시 시주 미표시. 지원하는 양력 입력 연도는 1900~2050년이며 미래 날짜는 거절합니다.
- 대운·세운·월운의 정밀 명리 계산은 아직 구현하지 않았습니다. 기존 2027년 월별 글은 공통 자기 성찰 가이드이며 개인별 월운이 아닙니다.
- 실제 결제/PG/환불 자동화는 **없습니다**. `paymentEnabled:false`이고 관리자 코드에 의한 테스트 발급만 가능합니다.
- Netlify 환경변수 `REPORT_TOKEN_SECRET`(32자 이상) 및 `DEMO_ACCESS_CODE`(12자 이상)는 별도 설정이 필요합니다. 값을 파일에 넣지 마세요.
- Netlify 배포 크레딧/배포 설정을 확인한 후 테스트 배포해야 합니다. 이 ZIP은 GitHub 및 운영 사이트에 자동 반영되지 않습니다.

## 테스트
프로젝트 폴더에서 `node --test` 실행.

## 배포 전 필수
1. 독립 만세력과 절기·자시 경계 대조
2. 서버 주문 생성→관리자 테스트 발급→웹 보고서 조회 통합 테스트
3. 실제 Toss Payments 계약/심사 후 서버 승인 검증과 발급 조건 연동
4. 개인정보 보관·삭제, 약관·환불 정책과 실제 제공 콘텐츠 일치 검토
